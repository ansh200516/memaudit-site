# memaudit-site

Landing page for **memaudit** — training-data memorization auditor for fine-tuned LLMs.

**Live:** https://ansh200516.github.io/memaudit-site/

Served by GitHub Pages from branch `main`, path `/`. `index.html` is fully
self-contained (inline CSS/JS); the only external dependency is Google Fonts.

## Redeploy

Edit `index.html`, then:

```sh
git add index.html && git commit -m "Update landing page" && git push
```

Pages redeploys automatically on push (usually live in under a minute).
